> **FUNCTIONAL REQUIREMENTS**

- The user needs to authenticate to access their long persistence data. Also access their data in any browser and device.
- The user can create actions/events even if not logged in. This data must be saved locally. If the user authenticates the data must be transferred for their account if first login.
- The user can use different sorters for actions and events: default (creation), color, alphabet and date.
- The user can filter for events: if it’s happening this month, next month, in 2, 3, 4, 5, or more than 6.
- The user can toggle between actions page and events page.
- The user can toggle between themes: light and dark.
- The user must be able to search for a specific event or action, by name.
- The user can download their events and actions into a PDF or sheets.
- The user can import their events and actions using a sheets with the columns: title, date and color
- The user can mark an event and action to no longer exist
- The user can select any event or action that won’t longer exist
- The user can delete all events or actions
