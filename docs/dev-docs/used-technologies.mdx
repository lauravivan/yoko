---
title: Used technologies
---

The idea is to build a light weight application, with a low number of dependencies.

Not a dependency

- **Local storage:** for store data that is not fully persistent

Dependencies

- **React:** for building reactive and dynamic interfaces. Use context with reducer to create global state management
- **React dom:** entry point to the DOM and server renderers for React
- **React router:** to enable navigation in SPA

Dev dependencies

- **Vite:** for bundling, HMR, etc
- **TypeScript:** to use types with javascript
- **Eslint:** to help with code quality and patterns
- **Prettier:** to help with code formatting
- **Husky:** automating eslint and prettier before commiting
- **Vitest:** writing unit and integration tests
- **Testing Library:** to test UI
- **SASS:** for styling
